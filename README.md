# Telecom Customer Churn Analysis

## Overview

This project analyzes telecom customer data to identify customer retention patterns and churn risk factors using Python, SQL, Power BI, and Machine Learning.

## Tools Used

* Python
* Pandas
* SQLite (SQL)
* Power BI
* Scikit-Learn
* Google Colab

## Key Insights

* Average Monthly Charges: $64.80
* Average Customer Tenure: 32.42 Months
* Fiber Optic is the most popular internet service.
* 55% of customers use Month-to-Month contracts.
* Model Accuracy: 79.24%
